# 《Token 计岛》视频介绍文案

> 用途：社区市场详情页 / B 站 / YouTube 短视频  
> 目标时长：**2 分 40 秒 ± 20 秒**（市场详情页建议再剪一版 45 秒精简版）  
> 形式：屏幕录制 + 口播，全程不需要真人出镜  
> 版本对应：插件 **v1.1.0**（WinIsland 宿主 SDK 2.4.0）

---

## 一、一句话定位（做封面与标题用）

**标题备选**

1. 把 AI 花费挂在灵动岛上：Token 计岛，一个 Windows 插件
2. 今天烧了多少 token、多少钱？看一眼任务栏就知道了
3. WinIsland 插件开发实录：本机 + 云端双来源的 AI 用量看板

**封面文案（不超过 12 字）**：`AI 花了多少钱，看一眼就知道`

**一句话简介**：Token 计岛把本机 AI 会话的 token 用量与估算费用直接显示在 WinIsland 灵动岛上，支持自定义模型单价，也可以接服务商的用量接口，接口挂了自动退回本地统计。

## 三、口播文案（分段，含时间码与画面提示）

### 【00:00 – 00:22】开场：痛点

> **画面：S1 → S2**

"用 AI 用得多了，其实很少有人真的知道自己花了多少钱。

控制台要看，账单要翻，很多工具甚至根本不告诉你今天烧掉多少 token。

这个我自己写的灵动岛插件，就叫 **Token 计岛**。它做的事很简单——**把今天的花费和 token 用量，直接挂在灵动岛上。**"

### 【00:22 – 00:52】是什么：三层信息密度

> **画面：S2 → S3 → S4**

"岛上有三层信息。

**最外面**，不展开的时候，就两个数：今日花费、今日总 token。一眼就能看完，不打扰你干活。

**鼠标悬停展开**，会多出输入、输出、缓存读的拆解，今天用了几个模型、每个模型各花了多少，还有本周、本月、累计。

**点一下岛体**，弹出一张大卡片——这里才是完整信息：四组 KPI、近七天的用量趋势、今日逐模型的明细表。点卡片外面或者按 Esc 就收回去。

（S3 处不停顿，让画面自己说话）"

### 【00:52 – 01:34】怎么用：单价是核心

> **画面：S5 → S6 → S8 → S9**

"用法上你只需要理解一件事：**费用是插件按你填的单价算出来的。**

因为会话记录里只有 token 数，钱是平台那边扣的，日志里的金额字段一直是零。所以打开设置页，把模型的单价照着你服务商的价目表抄进去就行——**按每一百万个 token 多少钱来填**，和价目表的写法完全一致。

四个框分别是：输入、输出、缓存读、缓存写。这里有个坑值得说：**缓存读通常比输入便宜很多**，而**缓存写反而比输入贵**。填反了，总费用能差一个数量级。

没填单价的模型，岛上是不会给你一个假的零的——它会明确显示「未定价」，不计入费用。我觉得这个诚实比好看重要。

其他设置都很直白：刷新间隔、会话记录目录、还有小岛常驻优先级——装了好几个插件的时候，谁占住岛面就是它说了算。"

### 【01:34 – 02:08】进阶：两个来源分列显示

> **画面：S6 → S10 → S11**

"1.1 版开始，它还能接**服务商的用量接口**。这里的设计我比较坚持一点：**本地日志降级为兜底，而不是被覆盖。**

为什么？因为很多人本地的会话记录和云端接口统计的，**根本不是同一个运营商**。我一开始写过一版是「云端数据优先，直接覆盖本地」，结果接上一个只有一天数据的网关之后，**本地 29 天的历史当场没了**。所以现在改成了按模型归属分派：两个来源各算各的，各用自己的货币符号，**绝不相加**。

所以你在图上会看到**双柱**——蓝色是本地，琥珀色是云端；柱高统一按 token 数算，因为人民币和美元没法比大小。金额写在柱顶。

接口地址、路径、字段名、分页方式全部可配置，内置几个预设可以一键套用。而且——**密钥不保存在插件里**，设置页只存一个环境变量名，运行时才去读。所以它不会落进任何配置文件、不会进日志、也不会出现在报错里。

接口一旦不通、超时、或者权限不够，插件会**自动退回本地日志**，并且在界面上明写当前数字是哪个口径。我不希望任何一次静默降级，让你看到一个偏小的数字还以为是今天用得少。"

### 【02:08 – 02:28】安装与卸载

> **画面：S12 → S7**

"安装很简单：WinIsland 打开插件市场，搜 **token-meter**，安装就好。卸载也干净——它的缓存全部写在插件自己目录里，**删插件的时候一起消失**，不会在你机器上留垃圾。

另外它是原生跟随岛体主题的，浅色深色都读得清，不用你管。"

### 【02:28 – 02:40】结尾

> **画面：S1 定格，叠字幕**

"代码开源，MIT 许可，插件市场直接搜 token-meter。如果你也想给灵动岛做点什么，可以看看仓库里的 README 和更新日志。

我是 KujouShiori，下期见。"

## 六、发布时的注意事项

1. **不要承诺自动对账**：口播里只说“按你填的单价估算”和“接口可用时以服务端为准”，不要说“和账单完全一致”——不同服务商的缓存口径确实存在差异。
2. **不要演示填入真实密钥**：环境变量名可以入镜，值不要。正好可以顺带讲“为什么不把密钥存在插件里”。
3. **金额与用量数据建议打码或用小号**：视频是公开的，今天的 80M token 能反推使用强度。
4. **版本对齐**：本片对应 v1.1.0；若后续升到 v1.2 并改了界面，重录前先在文案里把“双柱”“两栏 KPI”这些描述核一遗。
